## PROBLEM STATEMENTS 
- Develop a smart library management and recommendation system for 
university students. The system should not only manage traditional library 
activities like book search, book issuing, returning, renewal,availability 
checking, and due-date tracking, but also provide personalized book 
recommendations based on students’ reading history, interests, ratings, authors, 
topics, and reading patterns. 
- The system should allow students to search books, check availability, request 
book issue, reserve unavailable books, track issued books, view due dates, 
renew books, and get alerts for overdue books or fines. A librarian/admin 
should be able to manage books, approve issue requests, update return status, 
manage inventory, and generate reports. 
- In addition to library features, the system should include a Skill Learning 
Roadmap feature. If a student wants to learn any skill such as Python, Web 
Development, Data Science, Machine Learning, UI/UX Design, 
Communication Skills, or Cloud Computing, the student can enter the skill 
name and the system should generate a complete roadmap with beginner, 
intermediate, and advanced stages. It should also suggest free learning resources 
like YouTube playlists, official documentation, free courses, websites, articles, 
practice platforms, and project ideas. 
- The main goal is to build a complete smart academic support system that 
combines library management, personalized recommendations, book issuing, 
learning roadmaps, free resources, and progress tracking in one platform.
